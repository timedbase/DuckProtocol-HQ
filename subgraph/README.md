# DuckProtocol subgraphs

One subgraph per chain, deployed to Goldsky:

| Folder | Network | Goldsky name |
|---|---|---|
| `DuckSubgraph-RH/` | Robinhood Chain (4663) | `duck-subgraph-rh` |
| `DuckSubgraph-Ink/` | Ink (57073) | `duck-subgraph-ink` |

Both folders share identical schema, mappings and ABIs; only each manifest's network, addresses
and start blocks differ. They are generated by `gen_subgraphs.py` in this directory, which reads
the compiled contract ABIs from `DuckProtocol/deploy/out`.

## USD pricing

Both subgraphs price tokens in USD natively. Stablecoins are $1 (Robinhood: USDG, U; Ink: USDT0,
USDC bridged, USDG). ETH/USD comes from WETH/USDG on Robinhood, and from WETH/USDT0 and WETH/USDG
weighted by in-range liquidity on Ink. Other quote tokens use one reference pool each, listed in
`REF_POOLS` in `gen_subgraphs.py`; add a pool there to price a new quote token. Quote tokens with no curated
reference, such as arbitrary launcher quote tokens, get a pool discovered at runtime (see either
subgraph's README).

To change either subgraph, edit the generator and regenerate both:

```
python3 gen_subgraphs.py --force
```

Then build or deploy from each folder (`npm run build`, `npm run deploy`). See each folder's README
for what is indexed.
